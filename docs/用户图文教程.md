# HFE 角色定制工具图文教程

适用对象：第一次使用 `HFE角色定制工具.exe` 的玩家。

## 1. 下载与解压

拿到发布者提供的压缩包后，先把整个压缩包解压到一个普通文件夹里，例如：

```text
D:\Games\HFE角色定制工具\
```

解压后，文件夹里至少应该有这些文件：

```text
HFE角色定制工具.exe
使用说明.txt
图文教程.md
runtime/
```

不要直接在压缩包内部双击运行工具。一定要先解压。

`runtime` 文件夹里带着工具需要的 Java/JDK 环境。电脑没有安装 Java 也可以使用，但不要删除这个文件夹。

## 2. 启动工具

双击 `HFE角色定制工具.exe`。

工具会直接进入主界面。

如果双击后没有反应，先确认：

- 已经把压缩包完整解压出来，不是在压缩包内部运行。
- `runtime` 文件夹还在工具同一目录。
- 杀毒软件没有拦截 `HFE角色定制工具.exe`。

## 3. 认识主界面

进入工具后：

- **左侧**：`新建角色`、`打开项目文件夹`、`刷新`，下面是项目列表。列表按最近修改排序，每个项目下面显示角色 ID 和导出状态（绿点＝已导出，灰点＝未导出，红点＝导出失败）。项目多的时候可以在搜索框里输入项目名或角色 ID 筛选；右键项目可以在资源管理器中打开它的文件夹、`复制为新项目…`（做同一个角色的不同版本时很方便，会自动给一个新的角色 ID），或 `删除项目…`（项目只是被移到 `projects\_已删除` 文件夹，想恢复就拖回 `projects`）。
- **右侧顶部**：当前角色的名字、ID、模板和目标游戏，右上角是 `保存` 和 `导出游戏`。有没保存的修改时，名字旁边会出现 `未保存`，并多出一个 `放弃修改`。
- **右侧中间**：五个页面——`基本信息`、`外观贴图`、`技能道具`、`残影`、`校验导出`。页面名字旁边的小数字表示改了多少处（例如残影个数）；`校验导出` 旁边的红色/橙色数字表示有几个错误/警告。
- **最下面的状态栏**：显示刚才做了什么（例如“已保存”），右下角是实时校验结果，点它可以直接跳到 `校验导出` 页。

常用快捷键：`Ctrl+S` 保存，`Ctrl+E` 导出，`Ctrl+N` 新建，`Ctrl+1`～`Ctrl+5` 切换页面，`Ctrl+F` 搜索项目。

切换项目、新建项目或关闭工具时，如果当前项目有没保存的修改，工具会先问你要不要保存。

## 4. 新建角色项目

点击左侧 `新建角色`。新建窗口分三步：

1. **目标游戏**：默认是内置的 `HFE v1.0.2（内置原版）`。要改别的版本就点 `更换…` 选择游戏 EXE 或 SWF。第一次读取某个新版本需要解包分析，可能要几分钟，窗口里会显示进度；之后会直接用缓存。
2. **角色模板**：从列表里选一个现有角色当底子，可以在搜索框里输入名字筛选。
3. **项目信息**：填 `项目名称` 和 `角色 ID`。

信息不对时，输入框下面会直接用红字说明原因，`创建角色` 按钮在全部填对之前不能点。

这里的顺序很重要：不同 HFE 版本拥有的角色和道具不完全一样，所以必须先选游戏版本，再选角色模板。

### 角色 ID 怎么填

- 只用英文小写、数字和下划线，并且以小写字母开头。
- 长度必须和所选模板的角色 ID 一样长。例如模板是 `lucas`（5 个字符），ID 就要 5 个字符，比如 `eyj02`；模板是 `drew`（4 个字符），ID 就要 4 个字符，比如 `dre0`。
- 不能和原版角色重名。

选模板时工具会自动给出一个长度合适的 ID，直接用也可以。

## 5. 编辑角色基础信息

项目创建后会打开 `基本信息` 页：

- `角色身份`：角色 ID、英文名、中文名、角色说明。
- `基础属性`：HP、MP、防御值。
- `目标游戏`：显示当前用哪个游戏当底包，点 `更换目标游戏…` 可以换。
- `随机生成`：一键随机 HP/MP/防御、技能道具帧和部位贴图（角色 ID 和目标游戏不变）。生成后不满意，点右上角的 `放弃修改` 就能回到原样。

填错的内容会直接在输入框下面用红字提示，不用等到导出。改完按 `Ctrl+S` 或点右上角 `保存`。

> **中文名请用繁体字。** 游戏是用繁体中文（Big5）显示角色名字和说明的，很多简体字（例如“残、们、这、级”）在游戏里没有对应的字。以前这种情况导出时会悄悄改用英文名；现在工具会直接用橙字列出是哪几个字，换成繁体字（例如“殘”）即可。

如果目标游戏里已经有同样的角色 ID（例如往一个已经加过角色的游戏里再加角色），工具会马上提示，不用等导出失败。

## 6. 替换角色贴图

切到 `外观贴图` 页。每个部位（头部、身体、手臂、腿等）都可以换成游戏里其他角色**同一部位**的贴图，选 `保持模板原样` 表示这个部位不改。

- 改过的部位名字会变成紫色并带一个圆点，上方会显示“已替换 N / 11 个部位”。
- `把全部部位换成 … → 应用到全部`：一次把所有部位换成同一个角色。
- `全部恢复原样`：所有部位改回模板原样。

如果某个部位前面出现橙色的 `⚠`，表示换过去以后部件名长度变了，游戏里这个部位很可能会错位（鼠标停在部位名字上可以看到具体是哪些部件）。可以先导出进游戏看看，错位明显就换一个来源角色或改回原样。

## 7. 设置技能帧生成道具

切到 `技能道具` 页：

1. 左边 `动作` 列表里选一个动作。每一行前面是中文招式名（例如 `飞龙斩 动作1 · ball`），后面是动作代码；搜索框里输入代码或中文都可以（例如输入“升龙”）。鼠标停在某一行上会显示完整说明和帧数。中文名来自社区整理的 HFSE 人物 ac 代码表，工具会根据模板里实际有哪些动作认出是哪个角色（新版 HFE 会把角色位置挪给别人，比如 sinan 位置放的其实是林肯）；表里没有的动作只显示代码。改过道具的动作会显示成紫色并带圆点。打开 `只看会生成道具的动作` 开关，列表里就只剩原版会放飞行道具、召唤物的那些技能动作。
2. 右边 `选择帧` 里点一个帧号。带**灰点**的帧表示原版这一帧本来就会生成道具；带**粉点**的帧表示你已经改过。选中帧号后也可以用键盘 ← → 切换。
3. 在 `这一帧生成的道具` 里，每帧最多 3 个道具槽。道具下拉框可以直接输入编号或名字筛选（例如输入 `sword`），选 `无` 或点 `清空` 表示这个槽不生成道具。
4. 设置 `出现位置`（x / y / z）和 `初速度`（vx / vy / vz）。不是数字的格子会变红。
5. 想撤销这一帧的修改，点 `恢复本帧原样`。
6. 想让好几帧都放一样的道具：在设置好的帧点 `复制本帧`，再切到别的帧点 `粘贴到本帧`。

页面最下面的 `已修改的帧` 会列出所有改过的帧，点一下就能跳过去继续改。

### 常用参数理解

- `x`：横向位置。数值越大，越靠前。
- `y`：纵向位置。通常负数会更靠上。
- `z`：高度或层次相关位置。
- `vx`：横向速度。正数通常向前飞。
- `vy`：纵向速度。
- `vz`：高度方向速度。

如果只是想让道具正常出现在角色前方，可以先使用默认值，再进游戏测试效果。

## 8. 给角色添加残影

切到 `残影` 页。残影会重演角色若干帧之前的动作和走位，半透明显示，跟在角色身后。游戏是每秒 30 帧，延迟 30 帧大约就是 1 秒前的动作。

添加和删除残影的方法：

- **时间轴**：时间轴从 1 帧到 90 帧（下面标了 1 秒、2 秒、3 秒）。在时间轴上点一下就在那个延迟加一个残影，再点一下同一个位置就删掉；按住鼠标左右拖动可以连续添加或删除。
- **单个**：填一个延迟帧数，例如 `15`，点 `添加`。
- **批量**：填数量、起始帧和间隔，点 `批量添加`。下面会先预览将要添加哪些延迟。例如 `20` 个、从第 `1` 帧开始、间隔 `1` 帧，就是延迟 1、2、…、20 帧的 20 个残影。
- **常用**：一键添加常见组合，例如 `紧随 ×5（1–5 帧）`、`每秒一个（30/60/90 帧）`。
- `全部删除`：清空这个角色的残影。

时间轴下面会显示当前有多少个残影、分别延迟几帧。

规则：

- 延迟范围是 1-90 帧，每个延迟帧数只能有一个残影，重复添加会自动合并。
- 残影数量不设上限，但残影越多越吃性能。超过 30 个时会提示可能掉帧。
- 残影不能被攻击、不能被抓，不挡路，也没有血条。
- 角色死亡、换图或重开时残影会消失；剧情过场和被敌方时停时残影会暂停。
- 不管是玩家还是电脑在用这个角色，都会出现残影。

`残影行为` 里有两个开关：

- `残影可以造成伤害`：打开时，残影的拳脚和技能会真实命中敌人，也会真实抓人、投人；伤害和击杀都算在角色本体头上。关闭时，残影只是画面效果，不会碰到任何人。
- `残影可以发射道具`：打开时，角色本体发出的道具（飞行道具、召唤物等）会在残影的延迟之后由残影再发一次，命中算本体的。关闭时，残影不发道具。

如果把带残影的导出游戏再选作目标版本，继续给另一个角色加残影，前一个角色的残影设置会保留。

## 9. 校验并导出游戏

工具会在你修改时实时检查问题，右下角的状态和 `校验导出` 页都会显示结果。每个问题后面都有 `去修改 →`，点一下就跳到对应的输入框。

准备好以后，点右上角的 `导出游戏`（或在 `校验导出` 页点 `开始导出`）。工具会先自动保存，再做完整校验并生成新的游戏 EXE，导出过程中会显示已用时间，通常需要 1–3 分钟。

导出成功后，`导出结果` 里会显示游戏文件的位置，并提供：

- `▶ 启动游戏`：直接运行导出的游戏。
- `打开所在文件夹` / `复制路径`。
- `导出日志`、`校验报告`：出问题时发给发布者。
- `游戏内测试清单`：可以逐项打勾，方便一项项检查。

`导出记录` 里会列出这个项目以前导出过的游戏。

### 一个游戏里放多个原创角色

导出成功后点 `＋ 在这个游戏里继续加角色`（导出记录里每一行也有 `继续加角色`），工具会以刚导出的游戏为底包新建角色。这样导出的新游戏里，之前加的角色和它们的残影都还在。注意每个角色都要用不同的角色 ID。

## 10. 测试导出的游戏

导出后，双击新生成的游戏 EXE。

建议按下面顺序检查：

1. 游戏能正常打开。
2. 加载时没有警告弹窗。
3. 不会卡在加载界面。
4. 角色列表或 VS 选人界面能看到新角色。
5. 能选择新角色进入战斗。
6. 移动、跳跃、普通攻击正常。
7. 设置过的技能帧能正常生成道具。
8. 道具攻击判定正常。
9. 如果使用登录版本，结算时没有账号异常、封号或 hack 提示。
10. 如果加了残影：站着不动时残影和角色重合，走动、出招后残影按各自的延迟跟在后面重演；残影能不能打到人、能不能发道具，要和残影页的两个开关一致。

## 11. 常见问题

### 残影里出现红字 `AFTERIMAGE MOD DISABLED`

这表示残影功能在游戏里出错，已经自动停用，游戏本身还能继续玩。请把完整红字、使用的游戏 EXE 名称和出现时机告诉发布者。

### 需要自己安装 Java 吗

免 Java 发布版不需要自己安装 Java。压缩包里的 `runtime` 文件夹已经带了工具需要的 JDK。不要删除 `runtime` 文件夹，否则导出和目标版本读取可能失败。

### 选择目标版本后，角色模板变了

这是正常的。工具会按当前目标游戏版本读取角色模板。某些角色不是每个版本都有。

### 换了目标版本后，道具列表变了

这是正常的。每个版本的 `itemSpt` 可能不同，工具会按当前目标版本刷新道具目录。

### 导出失败

先看 `校验导出` 页面里的错误提示。常见原因包括：

- 角色 ID 不符合要求。
- 目标游戏文件路径无效。
- 选择了当前版本不可用的角色或道具。
- 某些贴图或素材文件不存在。

按提示修正后，再重新导出。

### 导出的游戏加载时警告或卡住

不要继续发布这个 EXE。把导出日志和游戏表现反馈给发布者或工具作者。

导出日志通常和导出的 EXE 在同一目录，文件名里会带：

```text
_export_log.md
```

### 贴图没有变化

确认：

- 对应部位不是 `保持模板原样`。
- 选择的图片文件没有被移动或删除。
- 导出后打开的是最新生成的 EXE，而不是旧 EXE。

### 贴图错位

可能是图片尺寸、部位或模板体型不匹配。可以换更接近原角色部位的图片，或先改回模板原样。
