# HFE 角色定制工具图文教程

适用对象：第一次使用 `HFE角色定制工具.exe` 的玩家。

## 1. 下载与解压

拿到发布者提供的压缩包后，先把整个压缩包解压到一个普通文件夹里，例如：

```text
D:\Games\HFE角色定制工具\
```

解压后，文件夹里至少应该有这些文件：

```text
HFE角色定制工具.exe
使用说明.txt
图文教程.md
runtime/
```

不要直接在压缩包内部双击运行工具。一定要先解压。

`runtime` 文件夹里带着工具需要的 Java/JDK 环境。电脑没有安装 Java 也可以使用，但不要删除这个文件夹。

## 2. 启动工具

双击 `HFE角色定制工具.exe`。

工具会直接进入主界面。

如果双击后没有反应，先确认：

- 已经把压缩包完整解压出来，不是在压缩包内部运行。
- `runtime` 文件夹还在工具同一目录。
- 杀毒软件没有拦截 `HFE角色定制工具.exe`。

## 3. 认识主界面

进入工具后，左侧是项目列表和常用按钮，右侧是当前项目的编辑区域。

常用按钮：

- `刷新项目`：重新读取当前工具目录下的项目。
- `新建角色`：创建一个新的自定义角色项目。
- `打开项目`：打开已有角色项目文件夹。

右侧有四个页面：

- `编辑角色`：填写角色 ID、名称、目标游戏版本等基础信息。
- `贴图与技能`：替换角色贴图，设置指定动作帧生成道具。
- `残影`：给角色添加延迟若干帧的残影。
- `校验导出`：检查项目并导出可运行的游戏 EXE。

## 4. 新建角色项目

点击左侧 `新建角色`。

新建窗口里，操作顺序是：

1. 先选择 `目标游戏 EXE/SWF`。
2. 等工具读取目标版本。
3. 再选择该版本可用的 `角色模板`。
4. 填写 `项目名称`。
5. 填写 `角色 ID`。
6. 点击 `创建`。

这里的顺序很重要：不同 HFE 版本拥有的角色和道具不完全一样，所以必须先选游戏版本，再选角色模板。

### 角色 ID 怎么填

推荐使用英文小写、数字和下划线，例如：

```text
ray0
app0
cx0
z_wrestle0
```

不要使用中文、空格或特殊符号。

部分角色模板对 ID 长度更敏感。比如某些模板原本是 4 个字符，导出时也更适合使用 4 个字符的 ID。工具会在校验时给出提示，按提示修改即可。

## 5. 编辑角色基础信息

项目创建后，会进入 `编辑角色` 页面。

这里可以修改：

- `项目名称`
- `角色 ID（按此 ID 导出）`
- `角色名称`
- `中文名称`
- `角色说明`
- `目标游戏 EXE/SWF`
- `目标类型`

改完后，点击 `保存并校验`。

如果只是普通玩家使用，通常只需要改角色名称和说明；目标游戏版本一般在新建时已经选好了。

## 6. 替换角色贴图

切到 `贴图与技能` 页面，找到 `部位贴图` 区域。

每个部位都可以选择：

- 保持模板原样。
- 使用新的图片文件。

建议只替换你确认对应的部位，例如头部、身体、手臂等。不同角色的骨骼和贴图命名可能不完全一样，如果替换后游戏内错位，可以回到工具里改回模板原样，或换一张更匹配的图。

### 贴图建议

- 图片尽量使用 PNG。
- 图片尺寸尽量接近原角色对应部位。
- 如果只是想先测试导出流程，可以全部保持模板原样。
- 如果导出游戏能进，但外观错位，通常是贴图尺寸或部位不匹配，不一定是工具导出失败。

## 7. 设置技能帧生成道具

在 `贴图与技能` 页面上方，可以设置某个动作的某一帧生成道具。

基本流程：

1. 在 `技能动作` 下拉框里选择动作。
2. 在 `动作内帧` 下拉框里选择帧。
3. 在道具槽里选择要生成的道具。
4. 设置 `x / y / z` 出现位置。
5. 设置 `vx / vy / vz` 初速度。
6. 保存项目。

每一帧最多可以设置多个道具槽。空槽表示不生成道具。

### 常用参数理解

- `x`：横向位置。数值越大，越靠前。
- `y`：纵向位置。通常负数会更靠上。
- `z`：高度或层次相关位置。
- `vx`：横向速度。正数通常向前飞。
- `vy`：纵向速度。
- `vz`：高度方向速度。

如果只是想让道具正常出现在角色前方，可以先使用默认值，再进游戏测试效果。

## 8. 给角色添加残影

切到 `残影` 页面。残影会重演角色若干帧之前的动作和走位，半透明显示，跟在角色身后。游戏是每秒 30 帧，延迟 30 帧大约就是 1 秒前的动作。

添加残影有两种方式：

- `单独添加`：填一个延迟帧数，例如 `15`，点 `添加`，就会多一个延迟 15 帧的残影。
- `快速添加`：填数量、起始延迟和间隔，点 `批量添加`。例如 `20` 个、从 `1` 帧开始、每个多延迟 `1` 帧，就是添加延迟 1、2、…、20 帧的 20 个残影；`3` 个、从 `30` 帧开始、每个多延迟 `30` 帧，就是延迟 30、60、90 帧的 3 个残影。

列表里会显示所有残影。选中后点 `删除选中` 可以删掉（按住 Ctrl 或 Shift 可以多选），`全部删除` 会清空这个角色的残影。

规则：

- 延迟范围是 1-90 帧，每个延迟帧数只能有一个残影，重复添加会自动合并。
- 残影数量不设上限，但残影越多越吃性能。超过 30 个时校验会提示可能掉帧。
- 残影不能被攻击、不能被抓，不挡路，也没有血条。
- 角色死亡、换图或重开时残影会消失；剧情过场和被敌方时停时残影会暂停。
- 不管是玩家还是电脑在用这个角色，都会出现残影。

两个开关：

- `残影本体可以造成伤害`：勾选时，残影的拳脚和技能会真实命中敌人，也会真实抓人、投人；伤害和击杀都算在角色本体头上。不勾选时，残影只是画面效果，不会碰到任何人。
- `残影可以发射 item`：勾选时，角色本体发出的道具（飞行道具、召唤物等）会在残影的延迟之后由残影再发一次，命中算本体的。不勾选时，残影不发道具。

设置完点 `保存并校验`，再去 `校验导出` 页面导出。

如果把带残影的导出游戏再选作目标版本，继续给另一个角色加残影，前一个角色的残影设置会保留。

## 9. 校验并导出游戏

切到 `校验导出` 页面。

点击：

```text
执行完整校验并导出
```

工具会先检查项目配置，再生成新的游戏 EXE。

导出成功后，结果区域会显示导出的 EXE 路径。通常导出的游戏会出现在工具所在目录。

## 10. 测试导出的游戏

导出后，双击新生成的游戏 EXE。

建议按下面顺序检查：

1. 游戏能正常打开。
2. 加载时没有警告弹窗。
3. 不会卡在加载界面。
4. 角色列表或 VS 选人界面能看到新角色。
5. 能选择新角色进入战斗。
6. 移动、跳跃、普通攻击正常。
7. 设置过的技能帧能正常生成道具。
8. 道具攻击判定正常。
9. 如果使用登录版本，结算时没有账号异常、封号或 hack 提示。
10. 如果加了残影：站着不动时残影和角色重合，走动、出招后残影按各自的延迟跟在后面重演；残影能不能打到人、能不能发道具，要和残影页的两个开关一致。

## 11. 常见问题

### 残影里出现红字 `AFTERIMAGE MOD DISABLED`

这表示残影功能在游戏里出错，已经自动停用，游戏本身还能继续玩。请把完整红字、使用的游戏 EXE 名称和出现时机告诉发布者。

### 需要自己安装 Java 吗

免 Java 发布版不需要自己安装 Java。压缩包里的 `runtime` 文件夹已经带了工具需要的 JDK。不要删除 `runtime` 文件夹，否则导出和目标版本读取可能失败。

### 选择目标版本后，角色模板变了

这是正常的。工具会按当前目标游戏版本读取角色模板。某些角色不是每个版本都有。

### 换了目标版本后，道具列表变了

这是正常的。每个版本的 `itemSpt` 可能不同，工具会按当前目标版本刷新道具目录。

### 导出失败

先看 `校验导出` 页面里的错误提示。常见原因包括：

- 角色 ID 不符合要求。
- 目标游戏文件路径无效。
- 选择了当前版本不可用的角色或道具。
- 某些贴图或素材文件不存在。

按提示修正后，再重新导出。

### 导出的游戏加载时警告或卡住

不要继续发布这个 EXE。把导出日志和游戏表现反馈给发布者或工具作者。

导出日志通常和导出的 EXE 在同一目录，文件名里会带：

```text
_export_log.md
```

### 贴图没有变化

确认：

- 对应部位不是 `保持模板原样`。
- 选择的图片文件没有被移动或删除。
- 导出后打开的是最新生成的 EXE，而不是旧 EXE。

### 贴图错位

可能是图片尺寸、部位或模板体型不匹配。可以换更接近原角色部位的图片，或先改回模板原样。
